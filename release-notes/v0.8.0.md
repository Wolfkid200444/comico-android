Download the APK below to update Comico for Android.

Changes in 0.8.0:
- Automatic chapter image saving for offline reading. A chapter becomes available offline once all its images finish saving.
- Saved chapters now appear in Library, including titles you haven't bookmarked.
- Restore the last local library and history when reopening offline. Account data stays separate.
- Disable online-only browsing, account, comments, leaderboard, and update actions while offline.
- Resume an available saved chapter when the last-read chapter isn't stored offline.
- Matching Discover and Search cover cards, with titles inside the artwork and square corners.
- Chapter numbers and update times on Discover cards when provided by the source.
- Search filters inside the search bar, with all manga types in the filter dialog.
- A dedicated Statistics page with library, reading, download, collection, and tag counts, plus distinct status-chart colors.
- Redesigned About page with version details, update checks, release changelogs, license links, and GitHub.
- Redesigned Help page with reading, library, offline, and sync guides and settings shortcuts.

Requires Android 8.0 or later. This debug build uses the repository's public test signing key and can update earlier GitHub builds signed with that key. The SHA-256 file contains the APK checksum.
