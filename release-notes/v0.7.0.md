Download the APK below and install it to update Comico for Android.

Changes in 0.7.0:
- Offline chapter downloads and ZIP imports, with automatic offline mode.
- Download selected chapters or all chapters in a source, language, and group.
- Compact chapter rows, comment indicators, and long-press read/unread actions.
- Library collection tabs, collection editing, filters, sorting, display modes, and random entries.
- Full-screen reader with translucent controls, chapter selection, and previous/next navigation.
- Remembered scanlation-group selections and dynamic source choices.
- Combined Data and storage settings for download locations, storage usage, export, history, and cache clearing.
- Fixed history sync errors caused by imported local ZIP entries and refresh loops.

Requires Android 8.0 or later. This build uses the repository's existing test signing key so it can update earlier GitHub builds. The SHA-256 file contains the APK checksum.
