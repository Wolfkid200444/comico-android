Download the APK below to update Comico for Android.

Changes in 0.10.0:
- Add automatic chapter notifications for your account library, with controls in Settings → Notifications.
- Add a foldable book view with two pages across a vertical fold, hinge spacing, and global or per-manga controls.
- Bring reading activity and library totals together in one Statistics screen.
- Track reading time, sessions, pages viewed, chapters viewed, and reading streaks locally, including offline reading.
- Add 7-day, 30-day, year, and all-time activity filters.
- Add hidden diagnostic tools: tap “Make yourself at home” seven times in Help to test notifications, check API access, and copy device diagnostics.

Reading activity tracking begins with this version. Chapter notifications require sign-in and Android notification permission; background checks may be delayed by Android’s battery settings.

Requires Android 8.0 or later. Signed with the same public test key as earlier GitHub builds. The SHA-256 file contains the APK checksum.
