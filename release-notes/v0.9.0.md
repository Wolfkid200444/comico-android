Download the APK below to update Comico for Android.

Changes in 0.9.0:
- Detect loss of internet access, including airplane mode and VPN connections, and switch to offline mode.
- Keep chapter downloads running in the background with a progress notification.
- Manage ongoing and saved downloads in Settings. Stop individual manga downloads or retry failed ones.
- Preserve the download queue and pause downloads while offline.
- Keep download errors with the manga that caused them.
- Show actual comment vote counts and your selected vote in Settings → Comments.
- Update comment actions without refreshing the whole tab.
- Add emoji reactions, threaded replies, and deletion of your own comments.
- Support collection names up to 120 characters. Collections remain local to this device.

Requires Android 8.0 or later. Signed with the same public test key as earlier GitHub builds. The SHA-256 file contains the APK checksum.
